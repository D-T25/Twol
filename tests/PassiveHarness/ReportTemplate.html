Twol · Passive guidance harness

Closed-loop tractor and trailing-tool simulation using the actual Twol guidance routine. These are model results, not field accuracy measurements.

What was exercised

The independent plant uses a bicycle tractor, steering delay/lag and differential trailer motion. GNSS noise uses fixed seeds. WinForms, UDP hardware and the desktop vehicle look-ahead model are not run. Look-ahead is a declared input. Manual profile settings are used throughout each run.
